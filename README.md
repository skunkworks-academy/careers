# Skunkworks Academy Careers

Candidate career-assessment and learning-path portal for Skunkworks Academy.

## Target service

- Public URL: `https://careers.skunkworksacademy.com`
- Identity: Microsoft Entra External ID
- Hosting target: Azure App Service
- Source control and CI/CD: GitHub Actions

## Product scope

1. Candidate registration and consent
2. Secure candidate sign-in
3. Online career assessment
4. AI-assisted and consultant-reviewed analysis
5. Personalised career growth and learning programme
6. Consultation scheduling
7. Proposal, enrolment and follow-up
8. Learning, certification and career-support hand-off

## Planned architecture

- Next.js and TypeScript candidate portal
- Microsoft Entra External ID authentication
- Azure App Service deployment
- Azure API layer and Azure SQL/Dataverse integration
- Power Automate for operational workflows
- Microsoft Bookings, Teams and SharePoint integration
- Azure OpenAI for draft analysis with mandatory human review

See `docs/implementation-plan.md` for the phased delivery plan.
